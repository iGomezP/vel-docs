## Engineering Decisions

### Frontend Testing

Playwright will be introduced at the beginning of Sprint 3.

Frontend functionality should include automated regression coverage as part of its delivery process.

Initial tests will use deterministic fixtures and controlled HTTP responses to avoid modifying the development database.

GitHub Actions integration is included in the testing foundation.

### UI/UX Strategy

The final VEL Workbench visual identity and comprehensive design system will be deferred until the application reaches greater functional maturity.

Current interfaces must still maintain acceptable usability, accessibility, and consistency.

### MCP Integration

MCP implementation remains outside Sprint 3.

The integration will be revisited after the application's core operations and authorization model become more stable.

RFC-0002 preserves the proposed integration direction.

### Work Item Deletion

Deletion and archival behavior must be defined before implementing destructive operations.

VW-025 will document the required architectural decision.
